# 🎓 College Complaint Management System

A Python-based College Complaint Management System designed to simplify the process of submitting, managing, and prioritizing student complaints.

## 📌 Project Overview

The College Complaint Management System provides a digital platform where students can submit complaints and administrators can manage them efficiently. The system uses Python and SQLite for complaint processing and data management.

## ✨ Key Features

- Student complaint management
- Admin management system
- Complaint priority handling
- SQLite database integration
- Separate student and admin interfaces
- Simple and user-friendly execution through batch files

## 🛠️ Technologies Used

- Python
- SQLite
- Database Management
- Batch Scripting

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/ritikchoudhary847/CollegeComplaintSystem.git
```

**2. Open the project folder**

```bash
cd CollegeComplaintSystem
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

Windows PowerShell:

```bash
venv\Scripts\Activate.ps1
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

Use the provided batch files:

- `run_student.bat` – Student interface
- `run_admin.bat` – Admin interface

## 🎯 Project Objective

The main objective of this project is to make college complaint handling more organized, efficient, and systematic through a Python-based digital solution.
